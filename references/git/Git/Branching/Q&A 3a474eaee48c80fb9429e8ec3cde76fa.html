Q&A

1. git switch & Remote Branches

Q: What happens if I run git switch origin/main?

A: Git gives an error because origin/main is a remote-tracking branch, not a local branch.

If you want to inspect it directly:

git switch --detach origin/main

This puts you in a detached HEAD state.

Q: What happens if I run git switch -c origin/main origin/main?

A: It creates a local branch literally named origin/main based on the remote-tracking branch.

⚠️ Avoid this because it can cause confusing/ambiguous branch references.

Q: What happens if I run git switch origin/main origin/main?

A: Git gives an error because git switch normally expects one branch/reference.

2. Local Branch vs Remote-Tracking Branch

Local branch

main

A branch that exists locally on your computer and that you can work on.

Remote-tracking branch

origin/main

Git's local record of where the main branch on the origin remote was last seen.

Think:

main        → my local branch
origin/main → my local reference to the remote main

3. How Does git switch <name> Find a Remote Branch?

If you run:

git switch login

and there is no local login branch, Git can often find:

origin/login

and create a local login branch that tracks it.

So:

git switch login
        ↓
finds origin/login
        ↓
creates local login

4. Does git switch Download New Code?

No.

git switch main

only changes your current branch/workspace.

It does not:

  • download changes
  • contact GitHub
  • merge changes
  • update origin/main

5. How Do I Update Local main From origin/main?

Standard way

git switch main
git pull

git pull essentially does:

git fetch
+
git merge (or rebase, depending on configuration)

Explicit way

git fetch origin
git merge origin/main

This gives you more control because you explicitly perform each step.

Force local main to exactly match origin/main

git fetch origin
git reset --hard origin/main

⚠️ This discards local commits/changes that aren't in origin/main.

6. Can I Make origin/main Into main?

Not literally.

origin/main and main are different references:

Local:
main

Remote-tracking:
origin/main

You can create a local main based on origin/main:

git switch -c main origin/main

This means:

Create a new local branch called main, starting at the same commit as origin/main.

It does not convert or rename origin/main.

7. Can I Make main Become origin/main?

You cannot directly turn a local branch into a remote-tracking branch.

origin/main is managed by Git as a reference to the remote repository.

It gets updated when you communicate with the remote, mainly through:

git fetch

For example:

GitHub:
    main
      ↓
   git fetch
      ↓
Local:
    origin/main

Then you can make your local main match it with:

git reset --hard origin/main

⭐ Easy Mental Model

GitHub
   │
   │ fetch
   ↓
origin/main
   │
   │ merge / rebase / reset
   ↓
main
