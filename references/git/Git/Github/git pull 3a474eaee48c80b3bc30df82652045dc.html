git pull

git pull with Tracking ✅

If your local branch tracks a remote branch:

main → origin/main

Then you can simply run:

git pull

Git already knows:

  • Remote → origin
  • Branch → main

It's roughly equivalent to:

git fetch origin
git merge origin/main

git pull without Tracking ❌

If your branch doesn't track anything:

feature/payment
(No upstream)

Running:

git pull

will give an error:

There is no tracking information for the current branch.

Git doesn't know where to pull from.

How to fix it

Option 1: Specify the remote and branch every time:

git pull origin feature/payment

Option 2 (Recommended): Set the upstream once:

git push -u origin feature/payment

or

git branch --set-upstream-to=origin/feature/payment

After that, you can simply use:

git pull
git push

Check if a branch has tracking

git branch -vv

Example:

* main             [origin/main]
  feature/login    [origin/feature/login]
  experiment
  • main ✅ Tracking set
  • feature/login ✅ Tracking set
  • experiment ❌ No tracking

Rule to remember

  • ✅ Tracking set → git pull and git push work without extra arguments.
  • ❌ No tracking → You must specify the remote and branch or set an upstream first.

If we run git pull origin in another branch

If you're on feature/signup and run:

git pull origin development

Git does:

git fetch origingit merge origin/development

What happens?

  • ✅ origin/development is updated from GitHub.
  • ✅ The latest origin/development is merged into your current branch (feature/signup).
  • ❌ Your local development branch is not updated.
