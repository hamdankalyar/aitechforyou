Git log

  • git log displays the commit history of a repository.
  • Each commit is a snapshot of the repository at a specific point in time.
  • It shows:
    • Author
    • Date & Time
    • Commit message
    • Commit hash

Commit Hash

  • Every commit has a unique hash (SHA).
  • You can use the first 7 characters as a short hash to refer to a commit.

Shows the commit history.

git log

Output:

commit 8f4a2d1
Author: Hamdan
Date: ...

    Add authentication

commit c31ab56
Author: Hamdan
Date: ...

    Fix login bug

Press q to exit.

-oneline

Shows each commit on one line.

git log --oneline

Output:

8f4a2d1 Add authentication
c31ab56 Fix login bug
b81f743 Initial commit

-decorate

Shows refs (branch names, tags, HEAD) pointing to commits.

Ref: A pointer to a commit.
  • Branch = Ref
  • Tag = Ref
  • HEAD = Ref
git log --decorate

Output:

8f4a2d1 (HEAD -> main, origin/main) Add authentication
c31ab56 Fix login bug

Show full ref names

git log --decorate=full

Output:

8f4a2d1 (HEAD -> refs/heads/main, refs/remotes/origin/main)

Hide refs

git log --decorate=no

Output:

8f4a2d1 Add authentication

-graph

Draws the branch history.

git log --graph --oneline

Output:

*   a9b42f1 Merge branch 'feature/login'
|\
| * 5e72b41 Add login validation
| * 2ab9310 Create login page
* | 81f32a7 Update README
|/
* 1a2b3c4 Initial commit

Symbols

  • → Commit
  • | → Branch continues
  • / \ → Branch splits or merges

-parents

Shows each commit's parent commit(s).

git log --parents --oneline

Output:

8f4a2d1 c31ab56 Add authentication
c31ab56 b81f743 Fix login bug

Format:

Current Commit   Parent Commit
8f4a2d1          c31ab56

Merge commit example:

a9b42f1 81f32a7 5e72b41 Merge branch 'feature/login'

Meaning:

Current Commit    Parent 1    Parent 2
a9b42f1           81f32a7    5e72b41
