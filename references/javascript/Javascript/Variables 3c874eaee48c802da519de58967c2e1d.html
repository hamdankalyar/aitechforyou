JavaScript Primitive Data Types

Data represents different values in a program. JavaScript has seven primitive data types:

1. String

A string is a collection of characters enclosed in single or double quotes.

const name = "Ali";

console.log(name[0]);                  // Output: A
console.log(name.indexOf("l"));        // Output: 1
console.log(name.indexOf("z"));        // Output: -1
console.log("super".length);           // Output: 5
console.log("ALOHA".includes("HA"));   // Output: true
console.log("ALOHA".startsWith("AL")); // Output: true
console.log("ALOHA".indexOf("HA"));    // Output: 3
console.log("ALOHA" + "!");            // Output: ALOHA!
console.log("ALOHA".toLowerCase());    // Output: aloha
console.log("aloha".toUpperCase());    // Output: ALOHA
console.log(Array.from("Ali"));        // Output: ["A", "l", "i"]

Important points:

  • String indexes start at 0.
  • indexOf() returns the first matching index or 1 if no match exists.
  • String searches are case-sensitive.
  • Spaces also count as characters.
  • String methods such as toLowerCase() return a new string; they do not modify the original.

2. Boolean

A Boolean has only two values: true and false.

3. Number

The number type includes whole and decimal numbers.

const age = 20;
const price = 10.5;

4. Undefined

undefined usually means a value has not been assigned or is accidentally unavailable.

let value;
console.log(typeof value); // Output: undefined

5. Null

null represents an intentionally empty or unavailable value.

console.log(typeof null);          // Output: object (historical JavaScript bug)
console.log(null === undefined);   // Output: false
console.log(null == undefined);    // Output: true
console.log(Number.isNaN(1 + null));      // Output: false (1 + null = 1)
console.log(Number.isNaN(1 + undefined)); // Output: true

Prefer strict equality (===) to avoid automatic type conversion.

6. BigInt

bigint stores integers larger than the safe limit of the number type.

const largeNumber = 12345678901234567890n;

7. Symbol

A symbol creates a unique value, commonly used as a unique object property key.

const id = Symbol("id");

Use typeof to check a value’s data type:

console.log(typeof "Ali"); // Output: string
console.log(typeof true);  // Output: boolean
console.log(typeof 25);    // Output: number
