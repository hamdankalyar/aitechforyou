# React Native lessons

- **Course:** The course lives at `/courses/react-native`.
- **Basics:** Start with setup, projects, and the React Native mental model.
- **Components:** Cover built-in components and reusable UI.
- **Styling:** Cover layouts, responsive screens, and platform differences.
- **Navigation:** Cover screen flows, parameters, and deep links.
- **State:** Cover local state and shared app state.
- **Device:** Cover storage, permissions, camera, and other native APIs.
- **Performance:** Cover lists, rendering, and release readiness.
- **Content:** Put article sections in `topics/react-native/content/`.
- **Registry:** Register each article in `lib/articles.ts` with its matching category.
